# 水景标签口径 V1.1

来源：三项目水景登记R02的“02_标签口径”。工作分类，不代表全部案例标签已确认。

| 层级 | 标签组 | 可选标签 | 判断口径 | 选择方式 |
|---|---|---|---|---|
| A 水景类型 | 静水 | 镜面水、静水 | 镜面水以倒影为主要效果；普通静水池选静水。不能判断水态时记未明确。 | 选最贴切的，不重复选上位静水 |
| A 水景类型 | 流水 | 坡面流水、滑水、水坡、溪流、水渠、附壁流水 | 滑水、水坡保留原专业表达，归入坡面流水检索分组，不直接相互替换。贴墙流选附壁流水。 | 不同部分可多选，不重复选上位词 |
| A 水景类型 | 跌落 | 跌水、叠水、水帘、瀑布 | 单级通常选跌水，连续多级选叠水，帘状落水选水帘，明确瀑布表现选瀑布。 | 同一段选最贴切的，不同部分可组合 |
| A 水景类型 | 喷泉 | 喷泉、涌泉、跳泉、珍珠泉、旱喷 | 不清楚具体水形时选喷泉；旱喷为与可呈干地状态的铺装场地整合的形式。 | 旱喷可与具体喷射形式组合 |
| A 水景类型 | 喷雾 | 喷雾、雾森 | 明确有喷雾设计时选择，仅有朦胧渲染不算。 | 选最贴切的，不重复选上位喷雾 |
| B 空间与构筑 | 水层特征 | 薄层 | 需方案说明或设计师明确，不只凭效果图推断水深。 | 选填，可与静水、流水组合 |
| B 空间与构筑 | 水面标高 | 齐平、抬高、下沉、多标高 | 看水面相对紧邻铺装的位置；下沉广场不自动代表水面下沉。多标高指不同高度水面。 | 选填，明确部位 |
| B 空间与构筑 | 依附关系 | 附壁、独立设置 | 看是否依附建筑立面或景墙。 | 选填，复合水景注明部位 |
| B 空间与构筑 | 构筑特色 | 台地、几何折面、水盒 | 台地为台阶状或多级平台组织；折面为多个倾斜面；水盒为盒式池体。 | 选填，可多选 |
| B 空间与构筑 | 几何特色 | 圆形、矩形、自由曲线、三角形分割、其他 | 注明整体轮廓或局部分割，以及对应部位。 | 选填，可多选 |
| B 空间与构筑 | 生态特征 | 生态水池 | 需有明确生态设计依据，可与静水、流水组合。 | 选填 |
| B 空间与构筑 | 关联设施 | 水舞台、亲水平台、观景平台、汀步、桥 | 水舞台按用户定义为水中或水上的实体小平台，不自动代表演出功能。 | 选填，可多选；设施单独关联 |
| C 功能与商业目的 | 互动与演艺 | 戏水、感应互动、水秀、光影瀑布表演、水幕表演 | 需明确戏水、行为响应或表演编排；有人靠近不算互动，普通照明不算演艺。 | 选填，注明作用对象 |
| C 功能与商业目的 | 体验与商业目的 | 空间引导、水声、氛围营造、视觉焦点、引流打卡、停留休憩、亲子参与、活动展示、品牌展示、降温 | 记录预期目标，不当作已实现的效果。 | 选填，可多选 |
| D 运行特色 | 运行与控制 | 分时运行、季节性运行、活动模式、感应控制、可编程 | 依据方案或运营说明。运行方式和感应需明确作用范围，不套用整个装置。 | 选填，可多选 |
