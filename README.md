# Landspire · 商业景观设计与知识中台前端原型

## 打开方式

推荐在项目目录运行 `node preview-server.cjs`，打开 `http://127.0.0.1:4173`。项目为静态前端，不需要安装依赖或启动业务后端。也可直接打开 `index.html`，但报告导出中的图片嵌入需要使用本地预览地址。

## 水景知识中心 V0.1（2026-10-02）

- 预览入口：`http://127.0.0.1:4173/#knowledge-center`。使用超级管理员演示账号进入“知识中心”。“项目知识”呈现已核对的成都秘境露台、深圳观城 V2 方案二门户下沉广场两个真实样本。
- 支持关键词、空间、水景类型与设计目标筛选；知识树按通用水景类型组织，项目空间名保留为实例名称。关键词检索仅匹配已确认的设计信息，不将“可能有收水槽”或澄清中的“动态水秀”作为确定事实返回。
- 样本详情包含设计逻辑、可点选的对象关系图、属性及其对应部位、来源依据、待补信息。点击来源编号可看图或用户说明，并可打开成都方案 PDF 第31页及下载原文件。
- “行业知识”展示工作模型的实体、属性和关系定义；“已发布知识”保留原有知识库及发布、复用授权筛选。样本内容确认不会更改知识发布状态、授权记录或设计助手参考资料。
- 原型沿用现有角色边界，仅拥有知识与资产查看权限的超级管理员显示结构化样本；其他角色仍进入原有已发布知识视图。这是本地前端演示，不提供服务端认证或对静态资源的访问控制，不应直接作为生产权限系统。
- 数据源为 `D:\商业景观知识中心资料库\04_结构化登记\待核对\水景知识结构V0.1_双样本_20261002`。`knowledge-samples-data.js` 与 `assets/knowledge-samples` 是该资料包的本地展示快照；修改 Excel、D盘资料或浏览器页面不会自动同步。
- 水景模型：`knowledge-model-core.js`；界面：`knowledge-center.js`、`knowledge-center.css`；快照生成：`tmp/water_review/prepare_frontend_data.mjs`。未来新增样本需更新结构化数据并重新生成展示快照，尚无上传、自动解析或写回资料库的功能。
- 检查覆盖精确类型、联合条件、否定/待确认排除、图谱跳转、图片与原文来源、手机布局和角色切换。预览使用独立浏览器上下文，不改动用户已有浏览器数据。

## 项目协作工作台（2026-10-02）

- 保留三种角色：设计师、项目经理、超级管理员。独立运营角色及其演示账号已移除；超级管理员统一负责项目、知识接入、审核、发布、下线、质量维护和账号权限。
- 项目工作台显示重点项目、进行中项目和待处理事项；独立项目列表支持关键词、项目阶段和项目状态筛选，并显示项目时间、下一节点、创建人、最近更新人及其操作、我的项目身份和当前交付版本。
- 系统角色为设计师、项目经理和超级管理员；项目内另标注唯一主创设计师、参与设计师和项目经理。项目经理可调整成员与主创，交接会留存时间和原因，历史版本作者不会被改写。
- 项目详情以“当前交付方案”为核心，展示方案理念、设计思路、需求/方案关键词及面积布局。正式版本按倒序显示修改原因、回应需求、版本差异和修改依据；未知资料一律标记为待补或待核实。
- 客户反馈可来自会议纪要、邮件或 AI 整理摘要。原文、来源、位置、关联版本和对象均本地留存；AI 摘要须由设计师确认。已被后续反馈替代的记录保留替代关系。
- “一键联动修订”先由设计师确认 AI 建议的影响范围和保留项，再一次创建多个专项任务。专项候选以 A1、A2、B1、B2 等独立迭代，绝不自动覆盖正式成果；预算、CAD 与专业图纸仅作为协同核验事项模拟。
- 主创可选择不同专项候选生成 C1 组合候选，保留来源候选和空间、排水、材料、预算、施工、图纸核验项；只有主创可将其确认成新的正式版本 V3。项目经理或超级管理员再从正式版本中手动指定当前交付，因此新 V3 不会自动替换 V2。
- 当前交付方案提供汇报视图和含嵌入图片的独立 HTML 导出，可通过浏览器打印为 PDF。原有设计助手报告仍在项目详情的折叠区域保留。
- 项目协作数据保存于 `landspire.project-collaboration.v1`；早期项目页的数据仍保留于 `landspire.projects.v1`。已提交的项目候选和正式版本在此浏览器内按项目成员共享；完整 AI 对话默认只对创建者可见，除非主动共享。
- 旧账号数据在该账号访问设计助手或项目页面时同步项目成果；不会改动其原始对话。项目发布与下线的具体业务规则仍待确认，现有知识发布流程保持独立。
- 主要文件：`project-collaboration.js`、`project-collaboration.css`、`auth-flow.js`；验证命令：`node --check project-collaboration.js` 与 `node --test tests/project-center.test.cjs`。测试使用独立内存存储，不修改用户浏览器数据。

## 设计助手与对话管理（2026-10-02）

- 三栏工作区：左侧历史对话、中间设计对话、右侧工作管理；较窄屏幕使用可收起侧栏。
- 历史对话支持新建、关键词搜索、按项目筛选、切换和重命名。一个项目可以关联多个对话；保存正式版本后固定对话的项目归属。
- 修改维度支持需求摘要、默认保留内容、场地关系、视角、总体布局及调整对象。修改要求变更后，需要重新确认才能生成候选。
- “修改版本”保存独立快照：需求、修改说明、维度、候选成果、原始消息、父版本、任务及操作人和时间。需求确认和成果确认分别记录；H001 延续既有 V1、V2，从 V3 编号。
- “项目 / 任务”管理草稿、版本成果和待办，可从历史版本另开对话继续。项目详情也展示助手中保存的版本和报告。
- “报告”可从版本生成阶段报告、最终设计方案、客户交付文档，支持预览和导出含嵌入图片的独立 HTML（浏览器打印可保存为 PDF）。最终方案与客户交付文档需先确认成果。
- 对话关键操作自动记录，版本可定位原始对话。报告保存生成时快照，不随后续版本确认或编辑变化。
- 新功能通过浏览器 localStorage 按登录账号保存；刷新后重新登录同一账号可继续。不同浏览器、不同端口或直接打开文件拥有不同的本地存储。达到浏览器容量限制时界面提示保存失败，可导出 JSON 工作记录；暂不提供导入和跨设备同步。
- 首次进入保持空白，可点击“载入演示对话”体验流程。需求解析为关键词模拟，候选使用现有 SVG 示意图，未接真实模型。确认人使用当前登录账号，不包含多人审批流程。
- 主要新增文件：`design-workspace.js`、`design-workspace.css`；继续兼容现有项目、知识库与角色菜单。

## 已实现页面

- 设计助手：反馈解析、设计师确认、策略编辑、双模式模拟出图、候选选择、版本对比和候选保存。
- 项目工作台与项目列表：分别用于聚焦工作和管理全部可访问项目。
- 项目详情：优先展示指定交付方案，倒序回溯版本与修改依据；手绘方案与会议纪要原件明确标为待补资料。
- 知识库：仅检索已发布、且授权范围允许复用的公司知识；知识可以带入设计助手作为参考。
- 我的知识提名：查看设计师主动提名后的审核状态；未提名的个人生成图不会进入知识审核后台。
- 资料接入：登记资料类型、项目、来源和授权状态。
- 知识资产：项目图片、策略、反馈、专业知识和成本维护记录。
- 审核队列：授权凭证复核与知识记录审核。
- 质量巡检：巡检状态、风险、整改与复检示意。
- 发布与版本：知识发布范围和版本关系。
- 标签与检索规则：标签字典、权限硬过滤、RAG 重排和巡检规则。
- 登录入口只接受账号并按账号匹配角色，不提供登录时选角色。可点选演示账号快速填入：设计师 `lin.jia@example.com`、项目经理 `pm@example.com`、超级管理员 `admin@example.com`；演示密码不校验。
- 登录页与工作台互斥显示，每种身份只显示自己的菜单。点击左下角“退出”返回登录页，可体验另一种身份；设计助手工作记录在本地保留，其他原有治理演示数据刷新后重置。
- 知识候选提名：设计师可从设计会话提名经验候选，需补充来源和边界后提交超级管理员；候选不会自动发布或跨项目复用。

## 演示数据说明

- `assets/h001-v1-*` 与 `assets/h001-v2-*` 是从 H001 资料复制的历史效果图。
- H001 图片的生成授权在现有资料中未找到凭证，因此默认为只可预览，提交凭证并经审核后才能作为参考图生成输入。
- `assets/candidate-*.svg` 是前端交互示意图，不是 AI 生成图片。
- 首次登录进入空白设计助手会话，后续恢复该账号的本地对话；打开 H001 项目详情时能看到已知的 V1、甲方反馈和 V2 关系。会议纪要日期和原件、手绘方案均未在资料中提供，页面明确标记为待补。
- 反馈解析、知识检索、巡检、审核、发布及出图目前均为本地模拟，没有连接真实模型或后端服务。
- 用户与权限页由超级管理员维护三种成员角色、模块操作权限和项目范围；完整设计对话保留在创建者账号下，其他有项目权限的成员查看共享版本及来源摘要。
- 登录与权限是前端演示，不执行真实身份认证或服务端权限校验，刷新后配置重置。生产环境需接入企业 SSO 和服务端 RBAC；权限变更审计可在后续设计。
- 成本只展示等级和依据；缺少工程量或报价时不会显示金额或节省比例。
